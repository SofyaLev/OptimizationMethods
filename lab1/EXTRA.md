## 1. Исходная задача

Рассмотрим задачу из [основного отчета](Отчет%20МетОпт%20лр1.pdf).

$$Z=x_1+2x_2+4x_3+x_4\to\max,$$

$$
\begin{cases}
x_1+x_2+x_3\le10,\\
x_2+2x_3+x_4=6,\\
x_1+x_4\ge2,\\
x_1,x_2,x_3,x_4\ge0.
\end{cases}
$$

В основной работе получены $x^*=(7,0,3,0)$ и $Z^*=19$. Дополнительно построим и решим двойственную задачу, затем потребуем целочисленность всех четырех исходных переменных.

## 2. Двойственная задача

В прямой задаче мы выбираем значения $x_1,x_2,x_3,x_4$, чтобы получить максимально возможное значение $Z$ при заданных ограничениях. Двойственная задача помогает установить, насколько большим вообще может быть этот результат. Ее переменные $y_i$ задают веса исходных ограничений. Взвешивая и складывая ограничения с подходящими знаками, можно получить верхнюю оценку целевой функции.

Каждое допустимое решение двойственной задачи дает число $W$, для которого $Z(x)\le W$ при любом допустимом плане $x$. Поэтому в двойственной задаче мы минимизируем $W$, чтобы получить наиболее тесную такую границу. Найденный прямой план показывает достижимый результат, а допустимая двойственная точка ограничивает результат сверху.

Это полезно для проверки оптимальности. Например, если план дает 19, а двойственная оценка равна 22, между ними остается разрыв и одного такого сравнения недостаточно. Если допустимый план дает 19 и допустимая двойственная точка тоже дает 19, улучшить результат уже невозможно. Число одновременно достигнуто и является верхней границей для всех допустимых планов. Для данной задачи именно так подтверждается оптимальность.

Для задачи максимизации с неотрицательными переменными двойственная задача является задачей минимизации. Первому ограничению со знаком $\le$ соответствует $y_1\ge0$, равенству соответствует свободная переменная $y_2$, третьему ограничению со знаком $\ge$ соответствует $y_3\le0$.

Целевая функция двойственной задачи составляется из правых частей исходных ограничений

$$W=10y_1+6y_2+2y_3\to\min.$$

Ограничения строятся по столбцам матрицы исходной задачи. Поскольку все $x_j\ge0$, они имеют вид $A^Ty\ge c$. Здесь $A$ содержит коэффициенты исходных ограничений, $A^T$ является транспонированной матрицей, а $c=(1,2,4,1)^T$ содержит коэффициенты целевой функции.

$$
\begin{cases}
y_1+y_3\ge1,\\
y_1+y_2\ge2,\\
y_1+2y_2\ge4,\\
y_2+y_3\ge1,\\
y_1\ge0,\quad y_2\in\mathbb R,\quad y_3\le0.
\end{cases}
$$

### 2.1. Запас ограничения

Запас показывает, насколько допустимая точка удалена от границы, заданной неравенством. Для ограничения со знаком $\le$ запас равен правой части минус левая. Для ограничения со знаком $\ge$ вычитаем правую часть из левой. У допустимой точки оба таких запаса неотрицательны.

Нулевой запас означает, что неравенство выполняется как равенство. Такое ограничение называют активным. При положительном запасе оно выполняется строго и является неактивным.

Для нашей задачи запасы двух неравенств равны

$$s_1=10-(x_1+x_2+x_3),\qquad s_3=x_1+x_4-2.$$

В найденной точке $x^*=(7,0,3,0)$ подставляем каждую координату

$$s_1=10-(7+0+3)=0,$$
$$s_3=7+0-2=5>0.$$

Первое ограничение активно, третье неактивно. Второе ограничение является равенством и выполняется точно, $0+2\cdot3+0=6$.

### 2.2. Условия дополняющей нежесткости

Дополняющая нежесткость связывает запас ограничения одной задачи с соответствующей переменной другой. Для оптимальных допустимых прямого и двойственного решений произведения этих величин равны нулю. Поэтому положительный запас требует нулевой соответствующей переменной. Если переменная ненулевая, соответствующее неравенство должно выполняться как равенство. При нулевом запасе условие само по себе не определяет значение переменной.

Для двух прямых неравенств получаем

$$y_1s_1=0,\qquad y_3s_3=0.$$

Переменная $y_2$ соответствует исходному равенству. Его остаток уже равен нулю, поэтому условие с этим остатком автоматически выполнено и не требует $y_2=0$.

Есть и вторая группа условий. Обозначим запасы двойственных неравенств через $d_j=(A^Ty)_j-c_j\ge0$. Тогда

$$x_jd_j=0,\qquad j=1,2,3,4.$$

Например, первому двойственному ограничению $y_1+y_3\ge1$ соответствует $d_1=y_1+y_3-1$. Если $x_1>0$, равенство $x_1d_1=0$ требует $d_1=0$, то есть $y_1+y_3=1$. Если $x_j=0$, соответствующее двойственное неравенство может иметь положительный запас.

Смысл этих условий можно увидеть через разрыв значений целей. На допустимых точках нашей задачи

$$W-Z=y_1s_1-y_3s_3+\sum_{j=1}^{4}x_jd_j.$$

Все слагаемые справа неотрицательны, поскольку $y_1\ge0$, $y_3\le0$, $s_1,s_3,d_j,x_j\ge0$. Чтобы прямое и двойственное значения совпали, каждое слагаемое должно обратиться в ноль. Это и выражают условия дополняющей нежесткости. При допустимости обеих точек выполнение всех этих условий подтверждает их оптимальность.

### 2.3. Применение к найденной точке

Используем $s_3=5$ в условии для третьего ограничения

$$y_3s_3=0\quad\Longrightarrow\quad5y_3=0\quad\Longrightarrow\quad y_3=0.$$

Запас $s_1=0$ дает $y_1\cdot0=0$ и пока не определяет $y_1$. Для его нахождения используем положительные исходные переменные. В прямой точке $x_1=7>0$ и $x_3=3>0$, поэтому

$$7(y_1+y_3-1)=0,\qquad3(y_1+2y_2-4)=0.$$

Делим соответственно на 7 и 3 и получаем равенства в первом и третьем двойственных ограничениях

$$y_1+y_3=1,\qquad y_1+2y_2=4.$$

Подставляя $y_3=0$ в первое равенство, получаем $y_1=1$. Из второго $1+2y_2=4$, поэтому $y_2=3/2$. Следовательно,

$$y_1=1,\qquad y_2=\frac32,\qquad y_3=0.$$

Проверим все двойственные ограничения

$$1\ge1,\qquad \frac52\ge2,\qquad4\ge4,\qquad\frac32\ge1.$$

Знаки переменных также допустимы. Значение двойственной функции

$$W=10\cdot1+6\cdot\frac32+2\cdot0=19.$$

По слабой двойственности для любых допустимых прямой и двойственной точек $Z\le W$. Мы нашли допустимые точки с одинаковым значением 19, поэтому обе оптимальны.

Смысл найденных весов можно проверить непосредственно. Умножим первое исходное ограничение на 1, второе на $3/2$ и сложим. Третье имеет вес 0 и в сумму не входит. Получим

$$x_1+\frac52x_2+4x_3+\frac32x_4\le10+\frac32\cdot6=19.$$

Левая часть равна $Z+\frac12x_2+\frac12x_4$. Поскольку переменные неотрицательны, она не меньше $Z$. Следовательно, для любого допустимого плана $Z\le19$. В найденной точке $(7,0,3,0)$ это значение достигается.

**Ответ** - $y^*=(1,3/2,0)$, $W_{min}=19=Z_{max}$.

## 3. Целочисленная задача

Добавим требование $x_1,x_2,x_3,x_4\in\mathbb Z_{\ge0}$, сохранив целевую функцию и ограничения. Это выбранная целочисленная версия исходной задачи.

Из ограничения-равенства

$$x_4=6-x_2-2x_3.$$

Перепишем целевую функцию

$$Z=x_1+2x_2+4x_3+6-x_2-2x_3=6+x_1+x_2+2x_3.$$

Первое ограничение дает $x_1+x_2+x_3\le10$, поэтому

$$Z=6+(x_1+x_2+x_3)+x_3\le16+x_3.$$

Из $x_2+2x_3+x_4=6$ и неотрицательности следует $x_3\le3$. Получаем верхнюю оценку

$$Z\le16+3=19.$$

Точка $(7,0,3,0)$ целочисленна и удовлетворяет всем ограничениям

$$7+0+3=10,\qquad0+2\cdot3+0=6,\qquad7+0\ge2.$$

В ней достигается оценка $Z=19$. Следовательно, это оптимум целочисленной задачи. Для равенства в оценках нужны $x_3=3$, затем из второго ограничения $x_2=x_4=0$, а из первого $x_1=7$. Оптимальная точка единственна.

В данном варианте непрерывный оптимум уже целочисленный. Поэтому добавление целочисленности не меняет ответ, разрыв между оптимальными значениями равен нулю.

## 4. Программная проверка

Отдельный файл [lab1_extra.py](lab1_extra.py) перебирает целочисленные решения и проверяет двойственный сертификат. Из ограничений следуют конечные границы $0\le x_1\le10$, $0\le x_2\le6$, $0\le x_3\le3$. Значение $x_4$ вычисляется из равенства. Поэтому перебор охватывает все допустимые целочисленные точки.

Функция `solve_integer` проверяет ограничения, вычисляет цель и сохраняет все точки с лучшим значением. Функция `find_dual` строит систему дополняющей нежесткости по найденной точке и решает ее через SymPy. Затем отдельно проверяет знаки двойственных переменных, двойственные неравенства и равенство значений целей. Если сертификат найден, он подтверждает также непрерывную оптимальность.

Получено 117 допустимых целочисленных точек. Единственный максимум достигается в $(7,0,3,0)$ и равен 19. Двойственная точка $(1,3/2,0)$ дает минимум 19. Эти результаты совпали с ручным расчетом.

Запуск из папки `lab1`

```bash
python lab1_extra.py
```

Для дополнительного скрипта необходим SymPy. При отсутствии библиотеки ее можно установить командой `python -m pip install sympy`.
