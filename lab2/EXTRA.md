# Дополнительное задание к лабораторной работе № 2

**Тема:** Метод ломаных

## 1. Задание и связь с основной работой

Требуется реализовать поиск константы Липшица через вторую производную и объяснить принцип. Для проверки выбрана функция из задания основной работы:

$$f(x)=x+\sin(3.14159x),\qquad x\in[-2,2].$$

Дополнительный расчет находится в [lab2_extra.py](lab2_extra.py). Поиск минимума выполняется исходным методом ломаных из [lab2.py](lab2.py).

## 2. Принцип вычисления константы

Константа Липшица ограничивает скорость изменения функции:

$$|f(x)-f(y)|\le L|x-y|.$$

Если первая производная непрерывна на отрезке, по теореме Лагранжа можно взять

$$L=\max_{x\in[a,b]}|f'(x)|.$$

Чтобы найти этот максимум для выбранной гладкой функции, нужно проверить концы отрезка и внутренние точки, где $f''(x)=0$. В этих точках первая производная может достигать экстремума. Точки с $f'=0$ дают нулевой модуль и не могут дать положительный максимум.

Алгоритм расчета:

1. Найти первую и вторую производные.
2. Решить уравнение $f''(x)=0$ на заданном отрезке.
3. Добавить к найденным точкам концы отрезка.
4. Вычислить модуль первой производной во всех этих точках и выбрать наибольшее значение.

Вторая производная нужна для поиска точек-кандидатов. Саму константу получаем по первой производной.

## 3. Зачем это нужно методу ломаных

Константа $L$ задает наклон вспомогательных функций:

$$g_i(x)=f(x_i)-L|x-x_i|.$$

При корректной константе нижняя ломаная не превышает исходную функцию. По ней метод выбирает следующую точку поиска и проверяет точность результата.

Если $L$ слишком мала, нижняя оценка может оказаться выше функции и критерий остановки потеряет гарантию точности. Если допустимая $L$ слишком велика, ломаная получается более грубой и обычно требуется больше вычислений для подтверждения точности.

Например, для $f(x)=x^2$ на $[-1,1]$ точная константа равна 2. После вычисления функции на концах нижняя оценка в середине равна $1-L$. При $L=2$ это -1, при $L=10$ это -9, хотя настоящий минимум равен 0. Большая константа оставляет больший разрыв между нижней оценкой и минимумом.

В основном коде константа оценивается по секущим на сетке с запасом 1.2. Такая оценка может пропустить участок с большим наклоном. Расчет через производные позволяет обосновать константу, если формула функции доступна и найдены все нужные точки. Полученную константу можно повторно использовать для той же функции на том же отрезке.

## 4. Работа дополнительного кода

Функция `find_l` получает выражение функции и границы отрезка. Через `sympy.diff` она вычисляет производные, а через `sympy.solveset` находит корни второй производной. Затем добавляет концы отрезка, подставляет все точки в первую производную и выбирает наибольший модуль.

Для выбранной функции, если обозначить $c=3.14159$, получаем:

$$f'(x)=1+c\cos(cx),\qquad f''(x)=-c^2\sin(cx).$$

Программа проверяет точки примерно $-2$, $-1.0000008447$, $0$, $1.0000008447$, $2$. Наибольший модуль первой производной достигается в нуле:

$$L=|f'(0)|=1+3.14159=4.14159.$$

Это также согласуется с оценкой $|1+c\cos(cx)|\le1+c$.

В `main` вычисленная константа передается исходному методу `pyavsky`. Перед передачей добавляется относительный запас $10^{-12}$ на округление. Для сравнения выводится прежняя сеточная оценка. Если для другой функции SymPy не сможет получить полный конечный список корней, программа сообщит об этом: неполный список не дает гарантии нахождения максимума.

## 5. Полученные результаты

Запуск выполнен с точностью метода ломаных $\varepsilon=0.001$.

| Показатель | Значение |
| --- | --- |
| Прежняя оценка константы по сетке с запасом 1.2 | 4.9699070074 |
| Константа через вторую производную | 4.14159 |
| Найденный аргумент минимума | -2 |
| Значение функции | -1.9999946928 |
| Число итераций метода ломаных | 11 |

Для выбранной функции получена более тесная константа, чем прежняя оценка с запасом. С ней исходный метод ломаных выполнил поиск минимума. Значение функции немного отличается от -2, поскольку в формуле используется число 3.14159, а не точное значение $\pi$.
